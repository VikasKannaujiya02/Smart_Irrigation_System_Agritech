# AI Smart Irrigation Dashboard Frontend

## Getting Started

1. Install dependencies:
```bash
cd frontend
npm install
```

2. Run the dev server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000)

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- Chart.js
- Lucide React (icons)
