# User Manual

## Getting Started

The AI Smart Irrigation Digital Twin provides an intuitive dashboard to monitor and control your irrigation system.

## Dashboard Overview

### 1. Live Sensor Data
- Soil moisture levels
- Air temperature and humidity
- NPK sensor readings
- Battery levels of sensor nodes

### 2. Pump Control
- Manual pump on/off
- Emergency stop
- Pump status and history

### 3. Weather Information
- Current weather conditions
- 24-hour forecast
- Rain prediction

### 4. AI Predictions
- Soil moisture forecasts
- Irrigation recommendations
- Prediction confidence levels

## Using the System

### Viewing Sensor Data
Navigate to the "Sensors" tab to see real-time sensor readings. Historical data is available in the "Analytics" section.

### Controlling the Pump
1. Go to the "Pump" tab
2. Click "Turn On" or "Turn Off"
3. Use "Emergency Stop" for immediate shutdown

### Viewing Analytics
The "Analytics" tab provides:
- Water consumption statistics
- Water savings from AI recommendations
- Crop performance metrics
- Trend analysis

### Managing Alerts
- View active alerts on the dashboard
- Click "Resolve" on an alert to mark it as addressed
- Alert history is available in the "Alerts" tab

## Backup and Restore

### Creating a Backup
1. Navigate to Settings > Backup
2. Click "Create Backup"
3. Wait for confirmation

### Restoring from Backup
1. Go to Settings > Backup
2. Select a backup from the list
3. Click "Restore"
4. Confirm the action

## OTA Updates
The system automatically checks for updates. If an update is available:
1. A notification appears on the dashboard
2. Review changelog
3. Click "Install Update"
4. System will restart automatically
